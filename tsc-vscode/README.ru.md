# CodeX TSC

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

Подсветка синтаксиса TSC, проверка ошибок и компиляция GSC в VS Code.

## Установка

1. Установите VS Code 1.74 или новее и LiarsoftTool из этой ветки.
2. В меню расширений выберите **Установить из VSIX** и откройте файл VSIX.
3. Найдите `liarsofttool.path` в настройках и укажите полный путь к программе командной строки LiarsoftTool: `liarsofttool.exe` в Windows или `liarsofttool` в Linux.

## Использование

Откройте файл TSC для редактирования. При сохранении он проверяется автоматически; результаты отображаются на панели «Проблемы».
В палитре команд доступны **CodeX TSC: Проверить сохранённый файл** и **CodeX TSC: Скомпилировать сохранённый файл в GSC**.
Перед ручной проверкой или компиляцией расширение предлагает сохранить несохранённые изменения. Подробности ошибок находятся в «Вывод → LiarsoftTool TSC».

Найдите `liarsofttool` в настройках:

- `path`: путь к программе командной строки LiarsoftTool.
- `encoding`: кодировка текста GSC, используемая целевой игрой; по умолчанию CP932. Файлы TSC сохраняются в UTF-8.
- `outputDirectory`: папка для GSC. Относительные пути отсчитываются от папки TSC. Пустое поле означает сохранение в ту же папку; существующие одноимённые GSC могут быть перезаписаны.

Проверка и компиляция требуют доверенного рабочего пространства. При удалённой работе установите LiarsoftTool на удалённом узле.
Интерфейс следует китайскому, японскому, английскому или русскому языку VS Code; для остальных используется английский.

## Локальная сборка

Нужны Node.js 22 или новее и собранный LiarsoftTool из этой ветки:

```bash
cd tsc-vscode
npm ci
npm test
npm run package -- --out liarsofttool-tsc.vsix
```

Для выбора компилятора в тестах используйте `LIARSOFTTOOL_PATH`.
