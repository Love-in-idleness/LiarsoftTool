# CodeX TSC

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

Создавайте сценарии TSC в VS Code из эпизодов, событий и связей, затем компилируйте GSC для оригинального движка.
Доступны профили **японской SevenBridge** и Forest.
Расширение находится в ветке `codex/tsc-vscode`, не в Marketplace. Оно не создаёт проекты Ren’Py, не копирует и не изменяет EXE игры.

## Установка

1. Установите VS Code 1.74 или новее и LiarsoftTool из этой ветки: редактору нужен интерфейс `--inspect-tsc`.
2. В меню расширений выберите **Установить из VSIX** и откройте локально собранный пакет.
3. Найдите `liarsofttool.path` в настройках и укажите полный путь к программе командной строки LiarsoftTool: `liarsofttool.exe` в Windows или `liarsofttool` в Linux.

Операции требуют доверенного рабочего пространства. При удалённой работе компилятор также должен быть установлен на удалённом узле.
В ограниченном режиме доступна только подсветка исходника. Меню, панели редактора и сообщения расширения следуют китайскому, японскому, английскому или русскому языку VS Code; для остальных используется английский.
Язык интерфейса не меняет кодировку проекта или существующий текст сюжета. Диагностика компилятора и системные ошибки сохраняют исходный язык.

## Новый сценарий

1. Подготовьте отдельную распакованную рабочую копию ресурсов законно приобретённой игры. Оригиналы оставьте только для чтения; ресурсы и проект должны быть раздельными.
2. Выполните **CodeX TSC: Новый проект TSC**, выберите SevenBridge, копию ресурсов и новую папку проекта. Номер первой сцены по умолчанию — `2001`.
3. Добавляйте в эпизод «Начало» диалоги, фон, персонажей, музыку, звуки, голос и паузы.
4. Создавайте узлы эпизода, условия, выбора или завершения. Соединяйте выходной порт с входом другого узла.
5. Сохраните файлы и нажмите «Сборка». Результат попадёт в `build/`, без автоматической установки в игру.

Сюжет хранится в `scr/*.tsc`, копии импортированных ресурсов — в `assets/`.
`tsc.project.json` содержит профиль движка, пути, персонажей, переменные, назначения ресурсов, кодировку и относительный каталог вывода. Он открывается кнопкой настроек.
Исходник TSC всегда UTF-8; GSC по умолчанию CP932. Целевая игра должна поддерживать выбранную кодировку.

## Редактирование и ресурсы

- Перемещайте события вверх/вниз, удаляйте их и редактируйте текст диалога. Для существующих команд доступны дополнительные параметры.
- Условия сравнивают целые переменные, выбор содержит 1–5 вариантов. Сначала добавьте именованную переменную, затем условие или присваивание/прибавление/вычитание.
  Убедитесь, что выбранный регистр не используется оригинальными сценариями: свободный диапазон не резервируется.
- Персонаж связан с оригинальной табличкой имени `gfNNN`; `999` означает повествование. Для нового изображения имени импортируйте ресурс таблички.
- Поддерживаются PNG/JPEG/BMP и OGG/WAV. Назначьте ресурсу имя и номер; поля номера предлагают имена импортированных ресурсов.
  Совпадение с оригинальным номером создаёт замену только в экспортированной сборке.
- При сборке изображения превращаются в WCG, OGG — в PCM WAV. Исходные ресурсы игры не меняются.
  Голос SevenBridge группируется по 10000: `10001 → voice/1/0001.wav`.

Кнопка «Исходник» возвращает текстовый редактор; **Открыть повторно с помощью → Открыть граф сюжета** возвращает граф.
Переименование обновляет ссылки на локальную метку; удалить узел со входящими ссылками нельзя. Ошибочный исходник доступен только для просмотра до исправления.
Открытие графа не переписывает неизвестные команды, исходные комментарии и метаданные GSC.
Позиции узлов и группы событий хранятся в комментариях TSC, а не в отдельной базе сюжета.

## Просмотр и проверка в игре

Статический просмотр показывает известные фон, персонажей, табличку и текст. Звук запускается вручную.
Координаты кадров LWG берутся из `.meta.xml`; отображается только первый кадр.
Для узла с несколькими входами можно выбрать контекст. Циклы, динамические выражения, нестандартные привязки и неподдерживаемые команды сопровождаются предупреждениями.
Просмотр не исполняет движок и не проверяет вёрстку текста, эффекты, меню или полный ход сюжета.

Новые сцены SevenBridge используют `modern-36 / rscript18`; оригинальный путь входа — `0100 → 0110 → 2001`.
Forest использует `legacy-28 / early`, первая сюжетная сцена обычно `1000`.
Диалект импортированного TSC сохраняется, без скрытого преобразования.
Собранные сцены по-прежнему требуют оригинальных сценариев запуска, меню и ресурсов. Упакуйте или поместите файлы из `build/` в реальные места чтения ресурсов
**отдельной тестовой копии оригинального движка**. Не заменяйте оригиналы. Расширение не устанавливает сборку и не запускает игру.
Параметры конвертации смотрите через `liarsofttool -h`.

Команды проверки и компиляции сохранённого файла работают и без проекта, используя настройки кодировки/вывода VS Code.
Сборка проекта использует `tsc.project.json`. Пустой каталог вывода отдельного файла означает запись рядом с TSC с возможной заменой GSC.
Ошибки видны в панели «Проблемы», подробности запуска — в «Вывод → LiarsoftTool TSC».
Старый вход конвертации Windows ограничен системной кодовой страницей пути; при ошибке используйте представимые пути.

## Локальная сборка

Нужны Node.js 22 или новее и собранный LiarsoftTool из этой ветки:

```bash
cd tsc-vscode
npm ci
npm test
npm run package -- --out liarsofttool-tsc.vsix
```

Тесты принимают `LIARSOFTTOOL_PATH`. `npm run build` собирает автономный интерфейс.

[Интерфейсы и данные движка](AUTHORING.ru.md) · [Справочник TSC](../docs/GSC_OPCODE_REFERENCE.ru.md)

Расширение распространяется под GPLv3. Интерфейс использует React, React Flow и их зависимости.
Полные лицензии упакованных зависимостей находятся в `dist/THIRD_PARTY_LICENSES.txt` внутри VSIX; инструменты сборки не включены. Ресурсы игр не предоставляются.
