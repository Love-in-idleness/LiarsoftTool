# CodeX TSC

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md)

Подсветка, диагностика существующим компилятором и сборка GSC для текущего формата
TSC LiarsoftTool. Расширение находится в ветке `codex/tsc-vscode` и не опубликовано
в Marketplace.

## Установка и использование

1. Установите LiarsoftTool с поддержкой `--check-tsc`; реализация есть в этой ветке.
   Расширение не загружает компилятор автоматически.
2. В VS Code выберите **Extensions: Install from VSIX** и откройте локальный VSIX.
3. Найдите `liarsofttool` в настройках. Укажите программу, кодировку игры и,
   при необходимости, каталог вывода. Если программы нет в PATH, нужен полный путь.

TSC сохраняется в UTF-8. Настройка кодировки относится к GSC; для японского текста
обычно используется CP932. В доверенном рабочем пространстве проверка выполняется
при открытии и сохранении TSC, ошибки появляются в Problems. При редактировании
старая диагностика очищается. Ручная проверка и компиляция предлагают сначала
сохранить изменения.

Команды:

- **CodeX TSC: Проверить сохранённый файл**
- **CodeX TSC: Скомпилировать сохранённый файл в GSC**

Пустой каталог вывода означает запись рядом с TSC. Существующий GSC может быть
заменён — сделайте резервную копию. Подробности ошибок доступны в
**Output → LiarsoftTool TSC**. В ограниченном режиме работает только подсветка.
Для удалённого рабочего пространства компилятор нужен на удалённой машине.

Пока возвращается первая ошибка в каждом файле. Семантическое автодополнение
и визуальный редактор не входят в эту версию. В Windows старый режим преобразования
ограничен путями, представимыми в системной кодовой странице; при необходимости
перенесите исходник и результат. Новый режим проверки поддерживает Unicode-пути.

## Локальная сборка

Нужен Node.js 22 или новее. В этом каталоге выполните:

```bash
npm ci
npm test
npm run package -- --out ../build/liarsofttool-tsc-0.1.0.vsix
```

`LIARSOFTTOOL_PATH` выбирает локальный компилятор для тестов. См.
[интерфейс диагностики](https://github.com/Love-in-idleness/LiarsoftTool/blob/master/docs/TSC_DIAGNOSTICS.ru.md) и
[справочник TSC](https://github.com/Love-in-idleness/LiarsoftTool/blob/master/docs/GSC_OPCODE_REFERENCE.ru.md). Лицензия — GPLv3.
