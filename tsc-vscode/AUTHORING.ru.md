## Работа с исходником

C++ `inspectTsc` использует токенизатор, таблицы параметров и проверку меток компилятора.
`--inspect-tsc <file>` и `--inspect-tsc -` возвращают JSON протокола 1 без записи GSC.
[Описание интерфейса](../docs/TSC_DIAGNOSTICS.ru.md). Смещения заданы байтами UTF-8;
расширение проверяет границы и переводит их в позиции UTF-16 VS Code.

`graph.js` строит граф из записей компилятора, не создавая вторую грамматику TSC.
Метки становятся узлами, переходы и выбор — связями. Неявный последовательный переход сохраняется.
Команды после return/end/jump остаются в исходнике, но не создают исполняемых локальных связей.
Меняются только выбранные токены или диапазоны событий. До WorkspaceEdit с поддержкой отмены новый текст проверяется C++.
Устаревшие версии и ошибочные исходники изменять нельзя. Посторонние комментарии и неизвестные команды не переставляются.

JSON проекта не дублирует сюжет. `;@editor-node` хранит заголовок/позицию,
`;@editor-event` / `;@editor-event-end` объединяют оригинальные команды в событие. Остальные комментарии обычные.
До вывода сборка проверяет все сценарии, кодировку и определимые вызовы сцен. Динамические вызовы сначала разрешите в исходнике.
Вывод не должен пересекаться с scr, assets и ресурсами; символические ссылки внутри путей запрещены.
Файлы заменяются через временный файл рядом с целью. Транзакции всего проекта нет: при ошибке ресурса исправьте её и пересоберите.

## Приоритет SevenBridge

Цель — японская `SBridge_jp.exe`, SHA-256:

```text
c7d5fc38cf0c354a61d056b607cf1367b2529557e9e0407d0b0fdf12771b35e3
```

[Данные оригинальной программы](https://github.com/Love-in-idleness/rscript2renpy/blob/main/sevenbridge/NATIVE_EVIDENCE.ru.md):
диспетчер `0x41cc40`, locmode с тремя параметрами `0x420220`, folder `0x4204e0`,
звук — cases `0x3e–0x40`, путь голоса — `0x41b5b0`.
Значения сверены со сценариями этой игры, а не угаданы по другим. В рамках этой задачи оригинальный EXE не запускался.

| Событие | Вывод SevenBridge | Основание |
| --- | --- | --- |
| Координаты/каталог | `locmode obj 0 0`, `folder obj "grpo"` | 0000 |
| Диалог | `TXT 0 voice 0 0 "" "^gNNNtext" 1` | 2001 |
| Изображение | queue, folder, locmode, `load layer id x y 0 0`, `update 0 0 0` | 0000, 2001 |
| Очистка | queue, `cls layer 0`, update | 2001 |
| Музыка | `bgm_on track 1 0`, `bgm_off 0 0` | 2001 |
| Звук/голос | `se id` + `se_on 0 0 0`; `voice id 0 0 0` | 2001 |
| Вызов/возврат | `gosub scene ""` и десять нулей; `return 0` | 2001 |
| Выбор | пять целей, пять текстов, в конце `0 0 0` | оригинальная таблица select, 1309 |
| Переменные | `0x1800` — присвоение; `0xa800/b800` и запись `0x1900`; сравнение `0x4800–9800` | 0000 и общий VM |

Новые сценарии: `modern-36 / rscript18`, locmode с тремя параметрами и одноканальный звук.
Существующие rscript19/modern не меняются; несовместимая вставка завершается ошибкой вместо замены диалекта.
Forest сохраняет `legacy-28 / early`: gosub принимает только номер сцены, bgm_on — один завершающий `1`, select — `2 0 0`.
Основание: исходные 0000/2100 Forest и таблица early ядра.

## Границы проверки

Node-тесты проверяют сохранность текста, Unicode, условия/выбор, события, пути, неудачные сборки и координаты просмотра.
`test/host.js` проверяет диагностику, граф, сборку SevenBridge и переход к исходнику в настоящем VS Code.
`test/browser.js` использует настоящий provider/компилятор с изолированными тестовыми данными.
Это не прохождение игры. Пути нативной Windows, реальная вёрстка текста и полный сюжет требуют ручной приёмки.
