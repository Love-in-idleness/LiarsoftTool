# LiarsoftTool

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md) | [日本語](README.ja.md)

Инструмент для ресурсов игр на CodeX RScript: упаковка и распаковка архивов, преобразование
изображений и аудио, извлечение, редактирование и сборка сценариев GSC.
Предназначен для произведений Liar-soft, raiL-soft и других авторов; поддержка зависит от игры.
Редактирование EXE экспериментальное и по умолчанию отключено.

Для создания проектов Ren'Py используйте отдельный [rscript2renpy](https://github.com/Love-in-idleness/rscript2renpy).

## Установка и начало работы

Загрузите программу для своей системы из [Releases](https://github.com/Love-in-idleness/LiarsoftTool/releases).
GUI и CLI распространяются отдельно: сжатые однофайловые EXE для Windows и отдельные бинарные файлы для Linux.
В Linux дайте файлу право на выполнение. Для GUI нужны GTK4 4.10+ и libadwaita 1.5+;
для аудио — медиабэкенд GTK и плагины GStreamer Ogg/Vorbis. В Windows GUI медиабиблиотеки включены.
Сборка из исходников описана в [руководстве](docs/BUILDING.ru.md).

Работайте с копиями игры. По умолчанию результат создаётся рядом со входом и может перезаписать одноимённые файлы.

1. Добавьте файлы или каталоги в задачи преобразования либо перетащите их в окно.
2. Проверьте кодировку и путь результата; при необходимости включите рекурсию, только упаковку или только распаковку.
3. Запустите преобразование. При сбое скопируйте полные сведения об ошибке.

GUI и CLI по умолчанию экспортируют GSC в TSC. Для извлечения только диалогов выберите **GSC→TXT** в GUI.
Кодировка по умолчанию — `auto`, автоматическое определение GSC. Короткий текст и смешанные кодировки могут потребовать ручного выбора.
Для японского обычно используется CP932, для китайских патчей — GBK. Компиляция GSC, упаковка и проверка кодировки требуют явного выбора;
`auto` не определяет кодировку имён в архивах и другого старого текста — для них остаётся CP932.

## Просмотр ресурсов

Открывайте каталоги, XFL, LWG и вложенные архивы без предварительной распаковки.
Диалоги выбора файла и каталога открываются в домашнем каталоге.
Выбранный элемент можно просмотреть как изображение, аудио, текст, GSC в виде TSC только для чтения или постраничные шестнадцатеричные байты.
Изображения поддерживают масштаб и прозрачный фон; аудио — паузу, перемотку и громкость.
При нечитаемом тексте смените кодировку; TSC всегда читается как UTF-8.

Просмотр не изменяет вход. Экспорт исходных байтов не преобразует формат.
Чтобы преобразовать элемент архива, сначала экспортируйте его и добавьте в задачи.

Параметры преобразования находятся справа на странице задач.
В настройках доступны системная/светлая/тёмная тема, язык, отдельная группа экспериментальных функций,
проверка обновлений, отправка сообщений о проблемах и руководство пользователя.
Поддерживаются китайский, английский, русский и японский; по умолчанию выбирается язык системы.
Ручная смена языка действует после перезапуска.
Обновления проверяются вручную с открытием страницы выпуска, без автоматической загрузки и установки.

## Редактирование сценариев

- TXT: впишите перевод после `>`. GUI использует одноимённый `.gsc` в той же папке: например, `scene.gsc` для `scene.txt`.
- TSC: измените команды и текст и скомпилируйте с кодировкой целевой игры. Сам TSC сохраняется в UTF-8.

GSC→TSC — экспериментальная функция. Сохраняйте исходный GSC, созданные метки и метаданные.
Успешное преобразование не гарантирует совместимость со всеми версиями движка.
Команды описаны в [справочнике TSC](docs/GSC_OPCODE_REFERENCE.ru.md).

## Редактор EXE (экспериментальный)

Включите его в группе экспериментальных функций в настройках: отдельная страница редактирует наборы символов шрифта, заголовки окон, управляющие сообщения, названия сцен и правила переноса.
Длинные переводы сохраняются в отдельный EXE; непроверенные элементы доступны только для чтения. Набор символов шрифта не меняет системную локаль Windows.
См. [руководство редактора EXE](docs/EXE_EDITOR.ru.md); параметры CLI для проверки и изменения перечислены в `liarsofttool -h`.

UTF-8 отсутствует среди кодировок ресурсов. Текстовые форматы, включая TSC, и модуль Unicode runtime сохраняют поддержку UTF-8.

## Экспериментальная среда исполнения

[RScript Runtime](runtime/README.ru.md) предоставляет загрузчик Windows, необязательные DLL, приоритет отдельных ресурсов и поддержку UTF-8.
Среда и конвертер сопровождаются в основной ветке. Сборка среды по умолчанию отключена; порядок сборки и использования описан в её руководстве.


[Документация](docs/README.ru.md) · [Сборка](docs/BUILDING.ru.md) · [Планы](docs/ROADMAP.ru.md)

Используйте законно приобретённые ресурсы и не публикуйте файлы игр.
