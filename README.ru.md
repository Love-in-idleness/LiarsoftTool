# LiarsoftTool

[中文](README.zh.md) | [English](README.en.md) | [Русский](README.ru.md)

LiarsoftTool обрабатывает ресурсы игр на CodeX RScript, включая произведения
Liar-soft и raiL-soft. Программа упаковывает и распаковывает архивы,
преобразует изображения и аудио, извлекает и собирает сценарии.

Для переноса игры в Ren'Py используйте её вместе с
[rscript2renpy](https://github.com/Love-in-idleness/rscript2renpy).

## Начало работы

В Windows распакуйте весь комплект и запустите `bin/liarsofttool-gui.exe`.
Не переносите EXE отдельно от библиотек и остальных файлов.
В Linux запускайте `liarsofttool-gui`. Консольная программа — `liarsofttool`.

Работайте с копией ресурсов игры. По умолчанию результат записывается рядом
с исходным файлом; повторное преобразование может заменить одноимённый файл.

1. Добавьте файлы или папки, либо перетащите их в окно.
2. Выберите кодировку ресурсов в параметрах: обычно CP932 для японского текста
   или GBK для китайских патчей.
3. При необходимости включите рекурсию, только упаковку или только распаковку.
   Проверьте задачи и пути вывода.
4. Запустите преобразование. Кнопка «Копировать подробности» копирует полный отчёт об ошибках.

GUI и CLI по умолчанию преобразуют GSC в TSC. Чтобы извлечь только текст
для перевода, включите **GSC → TXT** в параметрах GUI.

«Проверить обновления» проверяет новые выпуски вручную и позволяет открыть
страницу GitHub. При запуске программа не подключается к сети и не загружает
и не устанавливает обновления автоматически.

## Просмотр ресурсов

Откройте папку, XFL или LWG во вкладке «Ресурсы». Двойной щелчок открывает
подпапку или вложенный архив. Выберите запись для просмотра изображения,
аудио, текста или декомпиляции GSC в TSC только для чтения.
При неверном отображении текста смените кодировку; TSC всегда читается как UTF-8.
Неподдерживаемые и повреждённые файлы можно просматривать побайтово, по страницам.

Просмотр не распаковывает и не изменяет исходные файлы. «Экспорт исходных байтов»
сохраняет только выбранную запись без преобразования формата.
Для преобразования записи из архива сначала экспортируйте её, затем добавьте
в задачи преобразования. Отдельные файлы можно добавлять сразу.

Изображения поддерживают масштабирование и прозрачность. Для аудио доступны
воспроизведение, пауза, перемотка и громкость. Нужны медиабэкенд GTK и плагины
GStreamer для Ogg/Vorbis; полный комплект Windows их содержит.

## Справка CLI

Поддерживаемые форматы, параметры и примеры доступны в самой программе:

```bash
liarsofttool -h
```

## Перевод сценариев

Для изменения диалогов используйте TXT: впишите перевод после `>` и импортируйте
его, указав исходный GSC как образец. Для редактирования всего сценария
экспортируйте TSC, измените команды и текст, затем скомпилируйте его обратно.
Сохраняйте TSC в UTF-8, а для GSC выбирайте кодировку целевой игры.

GSC → TSC — экспериментальная функция; поддерживаются не все игры.
Сохраните оригинальный GSC и не удаляйте автоматически созданные метки
и метаданные TSC. Команды описаны в
[справочнике TSC](docs/GSC_OPCODE_REFERENCE.ru.md).

## Сборка из исходников

Нужны компилятор C++17, CMake, WebP, Vorbis/Ogg и libcurl 7.85 или новее.
Для GUI нужны GTK4 4.10, libadwaita 1.5 или новее и gettext.
В Windows и Linux используется один интерфейс.

В параметрах находятся настройки преобразования, системная/светлая/тёмная тема
и язык интерфейса. Поддерживаются английский, русский и упрощённый китайский;
смена языка применяется после перезапуска.

Debian / Ubuntu:

```bash
sudo apt install build-essential cmake pkg-config libwebp-dev libvorbis-dev libogg-dev libcurl4-openssl-dev libgtk-4-dev libadwaita-1-dev gettext gstreamer1.0-plugins-base gstreamer1.0-plugins-good
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
```

Программы находятся в `build/`. Для сборки только CLI добавьте
`-DBUILD_GUI=OFF` на этапе настройки. Сборка и упаковка для Windows описаны
в [отдельном руководстве](docs/BUILDING.ru.md).
