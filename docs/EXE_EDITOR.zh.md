# EXE 编辑（实验性）

[中文](EXE_EDITOR.zh.md) | [English](EXE_EDITOR.en.md) | [Русский](EXE_EDITOR.ru.md) | [日本語](EXE_EDITOR.ja.md)

修改已识别的 CodeX RScript PE32/x86 游戏中的字体字符集、内嵌文字和行首尾禁则。默认关闭，另存为独立 EXE。

## 使用

在“设置”的“实验性功能”中开启 **EXE 编辑（实验性）**，进入 **EXE 编辑** 页面。

1. 打开 EXE，确认原文本编码。显示乱码或无法确认时，明确选择原编码并重新检查；文件名中的 `gbk` 和字体字符集都不能证明文字已转码。
2. 选择目标编码。可编辑窗口标题、控制提示、错误消息及已识别的场景标题；原文与译文并列显示，无法确认引用的条目保持只读。
3. 点击 **使用目标编码的默认配置**，填入禁则、可识别的通用提示译文和标准字体名称。已在编辑框中手改的译文保留；游戏专属标题、场景名称仍需自行翻译。
4. 检查禁则，按需直接修改或加载 JSON，再点击 **另存为**。输入文件及其硬链接、符号链接别名不能作为输出。

切换文件、关闭窗口或关闭实验功能时，可选择保存、放弃或取消。分析和生成在后台执行；取消后丢弃过期结果。保存已经完成时，会明确报告取消来不及阻止保存。

CLI 支持只读检查、按条目标识修改文字以及应用默认配置。参数与示例见 `liarsofttool -h`。普通资源转换和目录递归不处理 EXE。

## 编码与默认配置

EXE 目标编码支持 CP932、GBK、CP950、CP949、CP1250–CP1258。字体字符集、原文本编码和 Windows 系统区域设置是不同事项；实际显示仍需匹配的 ANSI 代码页和字体。

| 目标编码 | 默认通用提示语言 |
| --- | --- |
| CP932 | 日语 |
| GBK | 简体中文 |
| CP950 | 繁体中文 |
| CP949 | 韩语 |
| CP1251 | 俄语 |
| 其余 CP125x | 英语 |

默认配置只匹配已知的原版通用文字或对应标准译文，不改写游戏专属文字和自定义译文。转码会处理已识别的文字；目标编码不能表示的内容需先翻译。

UTF-8 不作为资源编码提供，EXE 也不接受 GB18030。TSC、JSON、界面和路径仍使用 UTF-8；Unicode 运行时 DLL 保留。此功能不实现阿拉伯文塑形等复杂排版。

禁则 JSON 使用[运行时格式](../runtime/kinsoku.json)：`version` 为 `1`，`no_line_start`、`no_line_end` 为字符集合。集合不能相交，不能包含 NUL 或目标编码无法表示的字符；规则数量不受原表容量限制。

## 文字范围与限制

- 已验证引用的确认提示可使用长译文，保存时重定位文字并更新引用。游戏窗口不会自动重排，需在游戏中检查换行。
- APINI 窗口标题、场景表及其他固定字段显示可用字节数，超长会报错，不截断。外部 `RsInit.cfg` 或 `RsInit.dll` 可能覆盖内嵌标题。
- 其他代码引用的文字按安全容量编辑；格式占位符必须保留。资源键名、文件路径及控制符不作普通译文处理。
- 菜单若使用图片，其文字属于图片素材；通用 Windows 资源编辑、脱壳、已签名文件及不支持的代码布局不在范围内。

生成的 EXE 可重新打开继续编辑。分析不启动游戏或加载目标 DLL；保存前复核源文件，失败保留已有输出。

## 已核对的原程序

静态核对包含 SevenBridge 的 `SBridge.gbk.exe`（SHA-256 `ca0b635abe9861652182df0ed2ccc6854b580b1c8b41aa8ccf4368390944b74d`）与 Kagerou 的 `kagerou.exe`（`f02998fae350945f4de4dc7eab47997e1e2d9b8aa43d49740a80aad893dcde9b`）。两者没有标准菜单／字符串资源，菜单图片应另行翻译。前者字体已设 GBK，但内嵌通用提示仍为 CP932；后者含 APINI 标题与 12 个场景标题。

实现按 PE、指令和数据结构识别，不按游戏名或固定地址匹配。测试与静态核对不代表已完成完整汉化，也不替代原生 Windows 与完整游玩验收。
