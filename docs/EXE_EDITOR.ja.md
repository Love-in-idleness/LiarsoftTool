# EXE 編集（実験的）

[中文](EXE_EDITOR.zh.md) | [English](EXE_EDITOR.en.md) | [Русский](EXE_EDITOR.ru.md) | [日本語](EXE_EDITOR.ja.md)

認識できる CodeX RScript PE32/x86 ゲームのフォント文字セット、埋め込みテキスト、行頭・行末禁則を編集します。既定では無効で、別の EXE として保存します。

## 使い方

設定の「実験的機能」で **EXE 編集（実験的）** を有効にし、**EXE 編集** ページを開きます。

1. EXE を開き、元のテキストの文字コードを確認します。文字化けや不明な結果の場合は文字コードを明示して再解析します。ファイル名の `gbk` やフォント文字セットだけではテキストの変換済みを判断できません。
2. 出力文字コードを選びます。認識されたウィンドウタイトル、操作メッセージ、エラー、シーン名を編集できます。原文は比較用に残り、参照を確認できない項目は読み取り専用です。
3. **出力文字コードの既定の設定を使用** を押すと、禁則、既知の共通メッセージの翻訳、標準フォント名が入力されます。手動で編集した訳文は維持されます。作品名やシーン名は個別に翻訳してください。
4. 禁則を確認し、必要なら直接編集または JSON を読み込み、**名前を付けて保存** を選びます。入力自身や、そのハードリンク・シンボリックリンクへの出力は禁止です。

ファイルの切り替え、終了、機能の無効化時には保存・破棄・キャンセルを選べます。解析と生成はバックグラウンドで実行され、キャンセル済みの結果は表示しません。保存が先に完了していた場合はその旨を表示します。

CLI は書き込みなしの確認、テキスト ID による変更、既定の設定に対応します。引数と例は `liarsofttool -h` を参照してください。通常のリソース変換やディレクトリ再帰では EXE を編集しません。

## 文字コードと既定の設定

EXE の出力は CP932、GBK、CP950、CP949、CP1250–CP1258 に対応します。フォント文字セット、元の文字コード、Windows のシステムロケールは別の設定です。実行時には対応する ANSI コードページとフォントが必要です。

| 出力文字コード | 共通メッセージの既定言語 |
| --- | --- |
| CP932 | 日本語 |
| GBK | 簡体字中国語 |
| CP950 | 繁体字中国語 |
| CP949 | 韓国語 |
| CP1251 | ロシア語 |
| その他の CP125x | 英語 |

既定の設定は既知の標準原文と標準訳文だけに適用され、作品固有の文字や独自の訳文は置換しません。文字コード変更時には認識した文字列を変換します。出力で表現できない文字は保存前に翻訳してください。

UTF-8 はリソース文字コードとして提供しません。EXE では GB18030 も使用できません。TSC、JSON、UI、パスは UTF-8 を維持し、Unicode ランタイム DLL も残ります。アラビア文字の字形接続などの複雑な組版は実装しません。

禁則 JSON は[ランタイム形式](../runtime/kinsoku.json)を使い、`version` は `1`、文字集合は `no_line_start` と `no_line_end` です。集合の重複、NUL、出力で表現できない文字は拒否します。規則数は元の表の容量に制限されません。

## 編集範囲と制限

- 参照を検証した確認メッセージは、文字列の再配置により長い訳文を使用できます。ウィンドウ自体は再設計しないため、改行をゲーム内で確認してください。
- APINI タイトル、シーン表などの固定フィールドにはバイト容量を表示します。超過は切り捨てずにエラーとなります。外部の `RsInit.cfg` や `RsInit.dll` が埋め込みタイトルを上書きする場合があります。
- その他のコード参照文字列は安全な容量内で編集します。書式プレースホルダーは維持してください。リソースキー、パス、制御トークンは通常の翻訳項目として扱いません。
- 画像メニューの文字は画像素材の翻訳が必要です。汎用 Windows リソース編集、保護された実行ファイルの展開、署名済み EXE、未対応のコード構造は対象外です。

生成した EXE は再度開いて編集できます。解析はゲームを起動せず、対象 DLL も読み込みません。保存前に元ファイルを再確認し、失敗時は既存の出力を維持します。

## 確認した実行ファイル

静的確認には SevenBridge の `SBridge.gbk.exe`（SHA-256 `ca0b635abe9861652182df0ed2ccc6854b580b1c8b41aa8ccf4368390944b74d`）と Kagerou の `kagerou.exe`（`f02998fae350945f4de4dc7eab47997e1e2d9b8aa43d49740a80aad893dcde9b`）を使用しました。両者に標準メニュー／文字列リソースはなく、メニュー画像は別途翻訳が必要です。前者はフォント設定が GBK でも共通メッセージは CP932 のままです。後者には APINI タイトルと 12 個のシーン名があります。

識別には PE、命令、データ構造を使い、ゲーム名や固定アドレスで一致させません。テストと静的確認は完全な翻訳の完成を意味せず、Windows 実機と全編プレイの確認に代わるものではありません。
