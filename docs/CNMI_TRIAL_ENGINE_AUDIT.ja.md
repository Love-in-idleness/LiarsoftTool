## 試料と範囲

`ちんまい吸血姫体験版.exe`、SHA-256：
`21db7a449d329fb6bb030b1c1cf4050b0f519a52bd19167ba0d27dcc4cd6740e`。
静的な形式資料であり、実プレイ検証ではありません。EXE 編集は明示的に有効にする[実験的機能](EXE_EDITOR.ja.md)です。対応する操作はエディターの解析結果で確認してください。

PE ヘッダー、セクション、サイズ、コンパイル時刻、PDB は[中国語 Evermaiden](EVERMAIDEN_ENGINE_AUDIT.ja.md)と一致します。
`.text` の差は字体 charset の十バイトですが、文字列、初期データ、PE リソースにも差があり、同じファイルではありません。
`0x44dc33–0x44dc35` などは `IsDBCSLeadByteEx(CP_ACP, ...)` を使い、字体引数だけで全実行時の文字コードは決まりません。

## 空 LWG 項目

`grps.xfl/compane.lwg` は 32 項目です。空の `slide_lev_f` と `slide` は `(0,0)`、Flag 8。
別の非空 `slide` は `(690,4)`、`12×18` です。空項目を同名画像へ結び付けてはいけません。

展開は `empty="1"` で名前、座標、Flag、順序を保持し、画像は生成しません。
梱包側も印を読み、ファイルを探しません。空項目だけのアーカイブは拒否します。
失われたメタデータは原 LWG から再展開してください。

- `0x475722–0x47578c` は宣言された全項目を読みます。
- `0x427af2` は `slide_lev` を検索し、`0x427b7c` は `slide` をコントロールへ関連付けます。
- これらは名前のメニュー用途を示しますが、Flag 8 の全意味は確定しません。
- rscript2renpy でも空項目の識別を保ち、同名の非空項目の座標を上書きさせません。

## データ長

表直後の四バイトは余白ではなくデータ総長です。
`compane.lwg` の `0x2fd` は 30231（`0x7617`）、
ファイル長は 31000、データは `0x301` から正確に 30231 バイトあります。

梱包時は結合した実データ長を書き、空項目はゼロバイトです。
EXE は `0x475979–0x475981` で読みますが、これだけでゼロがクラッシュ原因とは証明できません。
デコーダーは従来のゼロ値も受け入れます。座標、順序、空項目、内容すべてが往復に必要で、
画像生成の成功だけでは完全な構造検証になりません。
