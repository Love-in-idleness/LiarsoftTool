# Интерфейс проверки TSC

[中文](TSC_DIAGNOSTICS.zh.md) | [English](TSC_DIAGNOSTICS.en.md) | [Русский](TSC_DIAGNOSTICS.ru.md) | [日本語](TSC_DIAGNOSTICS.ja.md)

Описание для авторов редакторов и инструментов. Пользовательские команды доступны
в `liarsofttool -h`.

`--check-tsc` запускает существующий компилятор в памяти, не записывая GSC.
Можно проверить несколько файлов; сейчас для каждого возвращается первая ошибка.
Код завершения — 0 при успехе и 1 при ошибке. Укажите целевую кодировку через `-e` (`auto` не принимается);
параметры преобразования, вывода и проверки обновлений несовместимы с этим режимом.

`--diagnostics=json` выводит в stdout объект:

```json
{"diagnostics":[{"file":"scene.tsc","severity":"error","message":"line 3: unknown command: missing","line":3,"column":null}]}
```

При отсутствии ошибок массив `diagnostics` пуст. Номера строк начинаются с 1.
Если позиция неизвестна или ошибка относится ко всему файлу, `line` равен `null`.
Точный столбец пока не определяется: `column` равен `null`, редактор выделяет строку
целиком. Ошибки параметров командной строки выводятся в stderr с кодом 1;
формат JSON для них не гарантируется.

Из C++ вызывайте `checkTsc(text, encoding)`, объявленную в
`include/gsc_decompiler.h`. Проверка использует те же синтаксис, параметры команд
и правила кодировки, что и компиляция. Не дублируйте компилятор в редакторе.

## Интерфейс графического редактора

`--inspect-tsc` принимает один файл или `-` для UTF-8 из stdin и возвращает JSON.
Проверка синтаксиса общая с компилятором, без ограничения целевой кодировки и записи GSC. Коды выхода: 0/1.
Протокол `version: 1` содержит `byteFormat`, `schema`, `lines`, `diagnostics`.
Строки содержат `kind`, `line`, `start`, `end`, `opcode`, `tokens`; токены — декодированное `value`,
`quoted`, `role` и диапазоны исходника. Диапазоны — полуоткрытые смещения байтов UTF-8 с нуля,
включая кавычки, а не столбцы UTF-16. Диапазон строки включает исходный перевод строки.
При ошибке записи могут быть неполными: сохраните исходник и запретите графические изменения.
Роли различают команды, метки, ссылки, строки, выражения и числа. Неизвестная семантика сохраняет opcode.
C++ API: `inspectTsc(text)`. Для старого инструмента сообщайте о необходимости обновления, не пишите другой парсер.
