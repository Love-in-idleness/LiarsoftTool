## Charset шрифта

В каждом EXE 12 прямых IAT-вызовов CreateFontA. Раньше менялись шесть, остальные сохраняли `0x80` после GBK.
Это другая раскладка PUSH компилятора, а не новая кодировка: между параметрами считаются вес/высота
либо нули задаются очищенными EBP/EBX.

| Форма | Операнд j.exe | Операнд kagerou.exe |
| --- | --- | --- |
| Нули EBP, постоянный вес | `0x45c173` | `0x457e83` |
| Расчёт веса EDI, высота EBP | `0x45ec5e` | `0x45c61e` |
| Расчёт веса EDI, высота EBX | `0x45efeb, 0x45f33e` | `0x45c9ab, 0x45ccfe` |
| Нули EBX, вес EAX | `0x45fa6f` | `0x45d42f` |
| Непосредственные нули, вес EAX | `0x45fcd6` | `0x45d696` |

Проверяется полная наблюдаемая форма, переменным остаётся только IAT-адрес. Меняется байт charset,
не произвольный PUSH 0x80, переход, адрес функции, вес или размер. Формы участвуют и в распознавании файла.
CP932 → GBK даёт двенадцать `0x86`; CP932 → GBK → CP1251 → CP932 восстанавливает оба EXE побайтово.
Имеющиеся таблицы переносов распознавались верно: по одной из 50 и 53 сравнений;
j.exe `0x44d104 / 0x45aca6`, kagerou.exe `0x4499d4 / 0x455126`.
Три расширения ASCII не меняются. Новых правил не добавлено. Системная кодовая страница всё ещё
должна соответствовать сценарию: шрифтовый патч не переключает все ANSI API.

## Имена LWG и XML

В `grps.xfl` образца `kagerou.exe` есть 46 пустых записей, из них 23 имеют имена вида `</Layer set>`.
Имена — данные архива, не разметка XML; пустые записи нельзя отбрасывать.

При извлечении экранируются `& < > " '`. Упаковщик декодирует только один слой XML-сущностей:
буквальное `&lt;` нельзя декодировать повторно.
Поиск изображений использует те же замены недопустимых символов, что и извлечение; LWG сохраняет исходные имена.
Сохраняются маркеры пустых записей, координаты, Flag и порядок. Некорректный XML нужно заново извлечь из оригинального архива.

Проверенное ветвление соответствует реализации. Реальные WCG только `0x0271`; новых LIM-образцов не найдено.
Статический анализ не проверяет все разновидности ресурсов; выходной PNG не доказывает поддержку PNG движком.
Прочитаны все верхние XFL и вложенные XFL/LWG, включая семь голосовых подархивов Jeanne,
пять Kagerou и архивы миниатюр, не только первые файлы.

Ogg из Jeanne voice.xfl/0001.wav полностью декодирован FFmpeg. Проверки контейнера и байтов
не подтверждают длительность, звучание в игре или совместимость ACM-драйвера.
Новый дефект преобразования аудио не обнаружен.
