# TSC 命令リファレンス

[中文](GSC_OPCODE_REFERENCE.zh.md) | [English](GSC_OPCODE_REFERENCE.en.md) | [Русский](GSC_OPCODE_REFERENCE.ru.md) | [日本語](GSC_OPCODE_REFERENCE.ja.md)

生成された TSC の命令と opcode 番号の一覧です。翻訳時は引用符内の文字列を編集し、自動生成ラベルとメタデータを保持してください。抽出・コンパイルのコマンドは `liarsofttool -h` にあります。

## 表の読み方

- **名前確定**: 名前とオペランド配置を確認した命令。
- **特殊構文**: 分岐、VM 演算などの生成形式。
- **意味未確認**: 引数配置は既知だが名前は未確認。`*opcode` で出力し、推測で置き換えない。
- 未知の命令配置は編集可能な命令として出力できません。

引数の記号は `E` が式、`D` が符号なし 32-bit、`H` が符号なし 16-bit、`S` が符号付き 16-bit。一部は引用符付き文字列です。世代によって配置が異なるため、TSC に記録された配置に従ってください。

実装は `src/gsc_decompiler.cpp`。すべてのエンジンが全命令を使うという保証ではありません。

## 意味が未確認の opcode

| Opcode | 既知の引数 | 十組のサンプルでの出現数 | 現在の処理 |
|---:|---|---:|---|
| `0x0054` | `E D` | 0 | 構造を保持して数値 opcode を出力。EXE・公式資料で意味が確認されるまで保留 |

`0x0054` は解析失敗でなく「構造既知・名前不明」です。コンパイラー・実行時の根拠なしに命令名を推測しません。

## VM 符号化の命令群

opcode の上位 4 bits がゼロでなければ単純な命令番号ではなく、演算子とアドレス指定方法を含みます。下位 bits は左右オペランドの即値、一時値、間接参照を表します。TSC は再コンパイル可能な完全形を `*vm 0xHHHH ...` で保存します。

| 上位群 | 演算 |
|---:|---|
| `0x1***` | 代入 `=` |
| `0x2***` | 論理 OR `\|\|` |
| `0x3***` | 論理 AND `&&` |
| `0x4***` | 等しい `==` |
| `0x5***` | 以上 `>=` |
| `0x6***` | より大きい `>` |
| `0x7***` | 以下 `<=` |
| `0x8***` | より小さい `<` |
| `0x9***` | 等しくない `!=` |
| `0xA***` | 加算 `+` |
| `0xB***` | 減算 `-` |
| `0xC***` | 乗算 `*` |
| `0xD***` | 除算 `/` |
| `0xE***` | 剰余 `%` |
| `0xF***` | ロード・移動 `mov` |

## TSC のメタデータ行

| 行 | 意味 |
|---|---|
| `;@gsc-byte-format modern-36` / `legacy-28` | ヘッダー長と Section D の宣言サイズ規則 |
| `;@gsc-schema <name>` | 命令配置 (`pre-codex`/`early-short-select`/`early`/`rscript18`/`rscript19`/`modern`) |
| `;@gsc-trailer <hex>` | Section D 後の全バイト（入口表二つと名前）。そのまま復元。既定は標準の空 9 bytes |
| `;@gsc-trailer-header <u7> <u8>` | 表と名前の長さを示す header word 7・8。既定は `4 1` |
| `;@gsc-raw-v1 …` | 命令配置を認識できない場合のファイル全体の raw fallback |

TSC は UTF-8 で保存し、GSC の文字コードは `-e` で選びます。
