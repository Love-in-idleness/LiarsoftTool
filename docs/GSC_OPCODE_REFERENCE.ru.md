# Справочник команд TSC

[中文](GSC_OPCODE_REFERENCE.zh.md) | [English](GSC_OPCODE_REFERENCE.en.md) | [Русский](GSC_OPCODE_REFERENCE.ru.md) | [日本語](GSC_OPCODE_REFERENCE.ja.md)

[Документация](README.ru.md)

Соответствия команд TSC и opcode. Для перевода меняйте текст в кавычках, сохраняйте
созданные метки и метаданные. Экспорт и компиляция описаны в `liarsofttool -h`.

## Обозначения

- **Именованная**: подтверждены имя команды и структура параметров.
- **Особый синтаксис**: переходы, операции VM и другие сгенерированные формы.
- **Семантика неизвестна**: структура известна, имя не подтверждено; выводится `*opcode`.
  Не подставляйте догадку вместо номера.
- Неизвестная структура инструкции не экспортируется как редактируемая команда.

`E` — выражение, `D` — unsigned 32 бит, `H` — unsigned 16 бит, `S` — signed 16 бит.
Некоторые параметры — строки в кавычках. Структуры поколений различаются: используйте
структуру экспортированного TSC. Реализация — `src/gsc_decompiler.cpp`.
Таблица не означает, что каждый движок использует все команды.

## Opcode с неизвестной семантикой

| Opcode | Сигнатура | Встречен в десяти наборах | Обработка |
| ---: | --- | ---: | --- |
| `0x0054` | `E D` | 0 | Сохранить структуру и числовой opcode; ждать подтверждения EXE или официальными материалами |

`0x0054` — известная структура с неизвестным именем, а не ошибка разбора.
Имя требует доказательств компилятора или runtime.

## Семейства VM

Ненулевые старшие четыре бита означают кодирование операции и адресации в самом opcode,
а не обычный номер команды. Младшие биты задают непосредственные значения, временные
переменные или косвенную адресацию обоих операндов. Полная компилируемая форма сохраняется
как `*vm 0xHHHH ...`.

| Старшая группа | Операция |
|---:|---|
| `0x1***` | Присваивание `=` |
| `0x2***` | Логическое ИЛИ `\|\|` |
| `0x3***` | Логическое И `&&` |
| `0x4***` | Равно `==` |
| `0x5***` | Больше или равно `>=` |
| `0x6***` | Больше `>` |
| `0x7***` | Меньше или равно `<=` |
| `0x8***` | Меньше `<` |
| `0x9***` | Не равно `!=` |
| `0xA***` | Сложение `+` |
| `0xB***` | Вычитание `-` |
| `0xC***` | Умножение `*` |
| `0xD***` | Деление `/` |
| `0xE***` | Остаток `%` |
| `0xF***` | Загрузка/перенос `mov` |

## Метаданные TSC

| Строка | Значение |
| --- | --- |
| `;@gsc-byte-format modern-36` / `legacy-28` | Длина заголовка и правило объявленного размера Section D |
| `;@gsc-schema <name>` | Структура команд: pre-codex / early-short-select / early / rscript18 / rscript19 / modern |
| `;@gsc-trailer <hex>` | Хвост после Section D: две таблицы входов и имена; по умолчанию стандартные пустые 9 байтов |
| `;@gsc-trailer-header <u7> <u8>` | Слова заголовка 7 и 8 задают размеры таблиц и имён; по умолчанию `4 1` |
| `;@gsc-raw-v1 …` | Полный исходный файл при нераспознанной структуре инструкций |

Сохраняйте TSC в UTF-8. Кодировка входного и выходного GSC задаётся `-e`.
